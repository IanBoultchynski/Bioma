# Modèles 3D des Biomes (`wwwroot/models/biomes/`)

Ce dossier contient les modèles 3D Blender (`.blend`), leurs exports WebGL (`.glb`) et leurs vignettes d'aperçu (`.png`) pour la **Vitrine 3D** (`/vitrine`).

> **Conversion automatique `.blend` → `.glb` + `.png`** : Lorsqu'un fichier `.blend` est déposé ici, `Showcase3DService` génère automatiquement le `.glb` et la vignette `.png` si Blender est installé.
